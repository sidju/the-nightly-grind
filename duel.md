# Duel

A duel is a harmless alternative to [Combat](combat.md). Instead of rounds and
dealing damage, just compare [Physical Ability](physical-ability.md) between the
sides (with Weapon bonus if weapons are used) and the higher number wins. No
powers are allowed.

This can be considered to be something like a contest of skill to first blood or
a wrestling match, where both [physical ability](physical-ability.md) and
technical skill defines the winner.

It is possible to add in powers using the following bonus table:

| Power                     | Bonus   |
| ------------------------- | ------- |
| [Fortitude](fortitude.md) | 1/level |
